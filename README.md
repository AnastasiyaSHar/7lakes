# Лендинг «Семь Озёр · Монстры»

Одностраничный сайт, посвящённый новогодним каникулам в стиле «монстры» в загородном комплексе «Семь Озёр» (85 км от Санкт-Петербурга).

## 🛠 Технологии

Проект сделан без использования сборщиков и фреймворков — только чистый код:
*   **HTML5** — семантическая разметка.
*   **CSS3** — адаптивная вёрстка (Flexbox, Grid), CSS-переменные, стеклянные карточки (glassmorphism), плавные анимации.
*   **Vanilla JavaScript** — анимации появления при скролле (Intersection Observer), параллакс, аккордеон FAQ, открытие формы.
